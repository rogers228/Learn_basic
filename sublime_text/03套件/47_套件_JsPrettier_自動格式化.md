# JsPrettier

儲存前自動格式化，適合團隊風格統一，尤其是前端
移除快速鍵設定，以下設定就可以達到儲存時格式化

設定 > Package Sitting > JsPrettier > Sitting Users

```
{
  "debug": false,
  "auto_format_on_save": true,
  "auto_format_on_save_requires_prettier_config": false,
  "auto_format_on_save_excludes": [],
  "file_extensions": [
    "js",
    "jsx",
    "ts",
    "tsx",
    "css",
    "scss",
    "less",
    "html",
    "svelte",
    "json"
  ],
  "custom_file_extensions": [
    "svelte"
  ]
}
```
