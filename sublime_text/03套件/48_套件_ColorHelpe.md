按下 Ctrl + Shift + P。

輸入 Package Control: Install Package 並按下 Enter。

搜尋 ColorHelper 並點選安裝。


點擊頂部選單 Preferences ➔ Package Settings ➔ ColorHelper ➔ Settings。

```
{
  "enable_interactive_previews": true,
  "inline_previews": "circle", // 可選: "square", "circle", "box"
  "color_formats": [
    "hex",
    "rgb",
    "hsl",
    "oklch"
  ]
}
```
