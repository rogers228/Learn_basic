# ToggleExclude


在 Sublime Text 中按下 Ctrl + Shift + P（Mac 為 Cmd + Shift + P）開啟指令面板。

輸入 Package Control: Install Package 並按下 Enter。

搜尋 ToggleExclude 並點擊安裝（安裝完成後左下角狀態列會提示成功）。


Toggle Exclude 的運作原理，是將你在 Sublime 中設定的 folder_exclude_patterns 與 file_exclude_patterns 進行開啟／關閉的切換。
